# EduGlobal CRM

نظام CRM متكامل لشركة استشارات تعليمية دولية، يربط الاستقبال والمستشارين والقبول والموارد البشرية والمالية والإدارة في منصة واحدة.

## المميزات

- تسجيل دخول بصلاحيات حسب الدور والقسم
- لوحة إدارة تعرض مؤشرات المبيعات والتحويل والإيرادات
- مسار مستشارين بأسلوب Kanban مع السحب والإفلات
- شاشة استقبال لتسجيل الاستفسارات وإنشاء العملاء المحتملين بسرعة
- مساحة قبول وتسجيل لإدارة الطلبات والمستندات ورفع الملفات
- قسم موارد بشرية لملفات الموظفين والحضور والأداء
- قسم مالي للفواتير والمدفوعات الجزئية والأرصدة والعمولات
- سجل نشاط مركزي يوثق التغييرات بين الأقسام
- ملفات طلاب مشتركة وربط تلقائي بين المراحل
- واجهة عربية متجاوبة تدعم `RTL`

## التقنيات

- الواجهة: `React` + `Vite`
- الخادم: `Node.js` + `Express`
- المصادقة: `JWT` + `bcrypt`
- رفع الملفات: `Multer`
- التخزين: ملفات JSON لسهولة العرض والتسليم

## التشغيل السريع

المتطلبات: `Node.js 18` أو أحدث.

```bash
npm install
npm run install:all
npm run dev
```

- الواجهة تعمل على: `http://localhost:5173`
- الـ API يعمل على: `http://localhost:4000`

## متغيرات البيئة

انسخ الملف `server/.env.example` إلى `server/.env` ثم غيّر قيمة `JWT_SECRET` قبل النشر.

## سير العمل الرئيسي

1. يقوم الاستقبال بتسجيل الاستفسار أو الزيارة أو المكالمة.
2. يتحول السجل إلى عميل محتمل ويُسند إلى مستشار.
3. ينقل المستشار العميل خلال مراحل المسار.
4. عند الوصول إلى مرحلة `Application Sent` يتم إنشاء طالب وطلب قبول تلقائيًا.
5. يدير قسم القبول المستندات وحالة الطلب.
6. ينشئ القسم المالي الفواتير ويسجل الدفعات.
7. تتابع الإدارة الأداء والتحويل والإيرادات بشكل مباشر.

## ملاحظات

- البيانات التجريبية موجودة في `server/data/db.json`.
- الملفات المرفوعة تحفظ داخل `server/uploads/`.
- هذا المشروع مناسب كنسخة MVP عملية، وللإنتاج الحقيقي يُفضّل استبدال JSON بقاعدة بيانات مثل PostgreSQL وربط التخزين السحابي للمستندات.
